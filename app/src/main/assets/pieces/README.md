# Piece artwork

Vector outlines of the chess glyphs U+2654-U+265F, extracted from these fonts (all 100x100 units,
common baseline, one `key=SVG path data` per line; `w*` = outlined/white glyph, `b*` = filled/black glyph):

| File | Source font | Licence |
| --- | --- | --- |
| `classic.txt` | DejaVu Sans | Bitstream Vera / DejaVu licence (free to use and embed) |
| `serif.txt` | GNU FreeFont - FreeSerif | GPLv3 with font exception |
| `pixel.txt` | GNU Unifont | GPLv2+ with font exception / SIL OFL 1.1 |

The app is GPLv3 (see the repository `LICENSE`), which is compatible with all of the above.
